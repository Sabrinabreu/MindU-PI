# MindU-PI

Uma solução robusta e segura que conecta empresas e seus colaboradores a profissionais qualificados da área de saúde mental. Através desta plataforma, empresas parceiras oferecem suporte psicológico e terapêutico como benefício, enquanto os funcionários ganham um canal seguro e personalizado para cuidar do seu bem-estar.

---

## Segurança e Privacidade

A privacidade é o pilar central deste projeto. O sistema foi desenhado para separar estritamente os dados corporativos dos dados de saúde:
A empresa contratante **não tem acesso** a nenhuma informação pessoal, histórico de consultas ou dados clínicos dos funcionários. O anonimato do colaborador é garantido por padrão.
> **Nota:** As empresas parceiras recebem apenas relatórios de engajamento macro, garantindo o sigilo médico/terapêutico de cada indivíduo em total conformidade com as diretrizes de saúde e proteção de dados.

## Como Executar o Projeto

### Pré-requisitos
Você vai precisar ter instalado em sua máquina as seguintes ferramentas:
*   [Git]
*   [Node.js]

### Clonando e Rodando

```bash
# Clone este repositório
$ git clone https://github.com/Sabrinabreu/MindU-PI.git

# Acesse a pasta do projeto
$ cd MindU-PI

# Instale as dependências
$ npm install

# Execute a aplicação no modo desenvolvimento
$ npm run dev

$ acessar em http://localhost:5173/
```
